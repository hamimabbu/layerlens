# Reporting a security issue

Use GitHub private vulnerability reporting if it is enabled for this repository. Share the smallest reproducible example, the affected version and the impact. Do not include real visitor addresses, personal profiles, credentials, private keys or raw packet captures.

For ordinary bugs, open an issue using synthetic or redacted data. Do not test the public demo against other visitors or arbitrary networks. Run the local test suite and use a disposable, owner-controlled deployment for security experiments.

The prototype has no independent production security audit. See `docs/THREAT-MODEL.md` and `docs/VALIDATION.md` for boundaries and remaining deployment checks.
